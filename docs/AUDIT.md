日期：2026-10-19。范围：应用自有前后端、配置示例、说明文档、构建及现有自动化测试。上游注册表/数据仓库仅确认职责边界；没有扫描依赖与编译产物。

## 审查发现与处理

| 发现 | 影响 | 本次处理 |
|---|---|---|
| README 的环境版本、配置路径、接口清单过时 | 无法按说明可靠建立环境/查找配置 | 中英文入口统一，新增完整功能与开发说明，接口/文件清单自动生成 |
| 主/分离窗口重复声明传输 payload | 同名事件的类型可能漂移 | 新增 `types/events.ts`，窗口路由按事件名推导 payload |
| 监听 promise 失败未捕获，卸载时回调缺少统一保护 | 未处理 rejection、已卸载路由仍可能处理事件 | 事件作用域管理注册、晚到清理、回调保护、幂等释放和错误隔离 |
| 网络活动回退匹配只比地址，不检查模式；空地址可能相等 | TCP/UDP 活动可能错误关联到当前通道 | 端点回退匹配要求正确模式和非空地址，明确通道 ID 语义保留 |
| `usePersistence` 同时维护类型、校验和副作用编排 | 配置合同难定位、校验难独立测试 | 拆分 JSON 类型与纯校验，保留 hook 的恢复/保存编排 |
| 终端布局校验仅检查浅层类型 | 错误引用、重复节点/标签、非法比例或深层树可能进入 renderer | 增加树与映射一致性、焦点/活动页、可选字段和深度校验 |
| 配置保存共享 `config.json.tmp` | 并发保存可截断/重命名另一保存的临时文件 | 每次保存使用独占唯一同目录临时文件；同步后替换；失败清理 |
| 示例脚本 CSV 增加字段后测试仍断言 29 列 | Rust 基线断言失败且不能证明列与数据匹配 | 改为验证列唯一且与实际输出行 key 完全一致，保留关键字段检查 |
| 文档声称 MIT 但根目录不存在 LICENSE | 对许可作出无依据声明 | 去掉声明与失效链接，记录实际缺失情况 |
