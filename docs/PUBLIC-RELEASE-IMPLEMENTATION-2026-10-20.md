## 已执行的验证

- `npm run check`：架构检查、TypeScript、生产前端构建通过；**46 个测试文件、337 项测试通过**。
- Rust 库回归：**169 通过、4 忽略**。忽略项目涉及额外运行条件，不计为通过；Unix 专用 discovery 权限测试无法在本次 Windows 主机执行。
- 原生 Core 集成：**7 项通过**，覆盖 token 鉴权、工具调用、TCP 客户端/服务端、UDP、同端口重新绑定、异步结果和 MCP stdio；测试用独立快照和回环端口。
- 导出纯源码到独立目录，使用**新的 npm 缓存**执行 `npm ci` 和 `npm run check`，337 项测试通过。Rust 构建使用当前机器已有 Cargo 缓存，这不等于全新机器完全无缓存验证。
- `npm audit`：全部依赖 **0 漏洞**。RustSec 全锁文件报告：`vulnerabilities.count = 0`，另有下述 2 条警告。
- Gitleaks 8.30.1：官方压缩包 SHA256 已核对；121 个历史提交及当前源码副本均未检出匹配的密钥。扫描不保证所有敏感信息均能识别。
- Windows NSIS 安装包构建成功；生产包包含 MIT、第三方声明和许可集合。当前产物为未签名预览版。
- Windows 实际 GUI：启动独立快照，通过本机 TCP 收包，终端显示 `01 10 20 40`，表格显示 `1/2、16/32、32/64、64/128`，折线图同步更新；设置对话框可按需加载。[实际截图](images/loopback-windows.png)已加入中英 README。
- 前端主 JS 从审查时的 778.01 kB / gzip 228.31 kB 降至约 **733.82 kB / gzip 221.15 kB**；另有按需加载块。未做标准化启动时间、峰值内存或硬件吞吐基准，不把体积减少等同于这些性能指标已改善。

## 仍需发布验收

1. **GTK 平台回归。** 原两项 Rust 告警已于 2026-10-21 回移修复/移除，并加入逐文件校验和上游身份审计；详见 [Rust 警告处理记录](RUST-WARNINGS-2026-10-21.md)。Linux CI 和实机回归尚未执行，仍需在 Linux 发布前验收。
2. **安装、升级、卸载与签名。** 已构建安装包，但没有可用的干净 Windows 虚拟机来验证安装/升级/卸载、WebView2 首装、旧配置保留和普通用户权限。没有签名证书；未修改本机现有安装来替代这些验收。
3. **GitHub 服务端。** 工作流已写入源码，尚未推送并在 GitHub Actions 执行；远端可见性、分支保护、私密漏洞报告、secret scanning/push protection 需维护者在仓库设置中确认。流程只创建草稿预览版本，人工验收后再公开。
4. **硬件和其他平台。** BLE 适配器/真实设备、串口设备、外部 pytest 工程及 macOS/Linux 实机仍需单独验证。Tailwind 4 需要近期 WebView；macOS 配置最低 13.3，但没有以配置值代替实测。
5. **历史内容。** 按维护者明确选择保留现有历史。旧快照、设备信息及运行记录仍可通过旧提交访问；当前版本删除不会从历史抹除。公开前应以此范围审阅历史。
6. **后续性能重构。** 已抽取独立职责并拆分加载。`scriptRuntime`、`mcp_tools` 等大模块未做全量机械拆分；应结合具体改动及性能基准继续分解，当前不宣称完成全面性能调优。
